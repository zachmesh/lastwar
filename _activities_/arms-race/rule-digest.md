# Rule digest

1. Each run reads and records the live phase score, working only to the top chest threshold (cadence-section-p1, cadence-section-p2).
2. Claim all earned chests, counter chest included, in one visit; leave no bouncing chest or red dot (cadence-section-p1, day-20261026-p3).
3. Never spend diamonds or money, burn speedups, swap stages or start research or building; record a shortfall as missed (cadence-section-p2, day-20261025).
4. Hero Advancement: one hero level from EXP only, +1 point per 2,000 EXP (day-20261026-p2, _records_/2026-11-10/arms-race/2209-queue-run.md).
5. Stamina: Free Claim first, then items, only if the gap can close inside the window; a 20-stamina kill pays 2,000 (cadence-section-p2, day-20261031-p1, _records_/2026-11-09/arms-race/1345-queue-run.md).
6. Training scores when queued; Tech Research and Base Building score free only when a completion lands in the window (day-20261025, _records_/2026-11-22/arms-race/1005-queue-run.md, day-20261026-p4, _records_/2026-11-10/arms-race/1756-queue-run.md).
7. The ranking row lags the live score; its chest is preview-only while live; an ended phase's reward is checked by Event mail (day-20261026-p4, run-20261109-1838, open-questions-p1).
8. Ground the Events icon fresh each unit (unverified, old ticker units) (how-to-enter-p1, how-to-enter-p2).

Unverified: queue rules R2, R4, R6 are undefined (_records_/2026-11-10/arms-race/1712-queue-run.md); window, Space and fullscreen notes (day-20261105) came from old ticker units; what raises the counter chest (day-20261026-p3); where an ended phase's reward is paid (open-questions-p1).

# Rule digest

1. Claim All pays a whole tab and shows a summary dialog; a red dot marks waiting gifts (how-it-is, how-to-enter).
2. A badge count is not the claimed count until the dialog confirms it (_records_/2026-11-01/alliance-gifts/1221-queue-run.md, run-20261117-0229-p2).
3. Re-check both tabs after claiming; clear means all rows Claimed, no Claim All, no red dot (_records_/2026-11-02/alliance-gifts/1215-queue-run.md, run-20261117-0229-p2).
4. Progress reads alliance-wide: judge a unit by dialog counts, not the bar. Rows read Regular 10; Premium R 50, SR 100, SSR 200, UR 500, MR 1000 (_records_/2026-11-11/alliance-gifts/1042-queue-run.md, _records_/2026-11-17/alliance-gifts/0229-queue-run.md, day-20261025, _records_/2026-11-07/alliance-gifts/1742-queue-run.md).
5. Never write the progress gain into stats.points; gifts closings carry no points key (how-it-is, scope-and-availability, _records_/2026-11-10/alliance-gifts/1310-queue-run.md).
6. Premium Claim All sits right of Regular's; ground each tab fresh; records leave the "Hide your name on Gifts" checkbox untouched. Unverified: old ticker coordinates (_records_/2026-11-11/alliance-gifts/1042-queue-run.md, _records_/2026-11-01/alliance-gifts/0110-queue-run.md).
7. Entry: Alliance panel, then Alliance Gifts; rail off-frame means stop. Unverified: old ticker framing (how-to-enter, run-20261110-0932).
8. Never press Escape; it quit the game app. Unverified: old executor key (run-20261103-1619-p2).
9. A failed unit is no evidence of gift state (run-20261105-0204-p2).

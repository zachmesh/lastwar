# Rule digest

1. Ghost Ops is a weekly event run from the third tab of the Secret Command Post; guide: Base Level 18 or above, account level 30, undated (what-this-activity, how-it-is).
2. Thursdays only, inside four server windows: 00:00 to 03:00, 06:00 to 09:00, 12:00 to 15:00 and 18:00 to 21:00 (how-it-is, cadence-section).
3. Guide: 3 missions each Thursday, completed in other warzones, team or solo; claim rewards manually, nothing is automatic (how-it-is).
4. Guide: helping allies earns rewards, 3 per day on the event day. On 2026-10-25 the Ally Team List was empty and help rewards read 0 of 3 (how-it-is, cadence-section).
5. Plunder (guide: 5 per day, pick UR) is PvP by the guide wording: a fixed red line, not a seat choice. Also no attack, rally, march, real-money purchase or diamond spend (how-it-is, cadence-section). Sources: OD-20261123-03 in `_records_/retro/owner-decisions-log/od-20261123-01.md`; OD-20261123-05 point 4 in `_records_/retro/owner-decisions-log/od-20261123-05.md`.
6. The 2026-11-05 ticker-2303 unit failed, Mac device offline: no screen read, no input, tracker untouched (failed-unit rule). It says nothing about missions, help or rewards; the 2026-10-25 inspection stays the last live read (run-20261105-2303-p1, run-20261105-2303-p2).
7. Auto Smart Task Execution was ticked at first sight and left as found; keeping it ticked is an open question (how-it-is, cadence-section).

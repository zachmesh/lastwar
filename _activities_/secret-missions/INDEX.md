# Secret missions

## What this activity is

Dispatching the Secret Command Post tasks and assisting allies with
theirs. This folder accumulates secret mission knowledge - task types,
durations, rewards and the assist cap. Executions are recorded in
`_records_/<date>/secret-missions/`, one file per execution. The same
post screen carries two sibling tabs registered as their own types -
[`hidden-treasures`](../hidden-treasures/INDEX.md) and
[`ghost-ops`](../ghost-ops/INDEX.md).

## How to enter

- The post opens from a slot in the base left icon column (observed
  around norm (56,643) and later (48,643)). The column carries two
  rotating shortcut sets, so the same slot can open Intercity Trade
  or the radar instead - always verify the title SECRET COMMAND POST
  before tapping further.
- Measured 2026-11-01 - a first tap at norm (52,643) opened the post
  and the title was verified before acting, a third observed slot
  point for this entry.
- The screen has three tabs - Secret Tasks, Hidden Treasures and
  Ghost Ops. Secret Tasks itself shows Your Tasks with a count badge
  and an Others' Tasks or Ally Tasks list below.

## How it is done - dispatching

- Normal dispatch sends one task at a time from Your Tasks.
- The Mega button at the bottom switches the bottom bar to Mega
  Refresh, Mega Deploy and Normal. Mega Deploy opens the MEGA
  DEPLOY REMINDER panel - every pending task listed with its
  duration and an auto assigned hero team (some tasks get only two
  heroes), a checkbox per task, a UR Only filter that starts on,
  and a Perform Now button that sends everything checked at once.
- Unchecking UR Only resets every checkbox to empty - after
  unchecking, re-check each task by hand before Perform Now. The
  panel scrolls for long lists.
- Mega Refresh rerolls the pending task list. Its cost was not
  observed - the evening run did not need it.
- Standing rules, owner taught 2026-10-25. One - for the Secret
  Mobile Squad, use Mega Deploy by default on most days. Two - on
  Alliance Duel days when UR secret tasks count toward the duel
  score, first use Mega Refresh to roll UR tasks, then deploy.
  Three - when dispatching via Mega Deploy, unselect UR Only so
  every squad deploys.

## How claiming works

- A finished task shows a Claim button. Claiming any one finished
  task collects ALL finished tasks at once - observed twice on
  2026-10-25, in the morning batch and again in the evening. Each
  claimed card is stamped PERFECT in gold, and the Your Tasks badge
  clears.
- Morning batch claimed - UR Rescue Officer, UR Rescue Missing
  Agent, SSR Search for Missing Refugees, SSR Protect Refugee Camp.
  Rewards included Treasure Map Fragments number 7, 4 and 1, a full
  Treasure Map, a Resource Chest, Upgrade Ore and a 5 minute
  Research Speed-up.
- Evening batch claimed - the four 30 minute tasks together paid
  Mystery Supply Box times 100, Hero EXP 4.9M, Skill Medal times
  440, Refined Iron Module times 150, iron 975.0K, food 975.0K and
  Upgrade Ore times 240.

## Cadence

- Own tasks run on timers from 30 minutes to 4 hours; claim when
  finished, then new tasks can be dispatched. Ally assists cap at 5
  per day. The post belongs in every daily round.

## Scope and availability

- Permanent system, no season gating observed. Task rarities seen -
  SR, SSR and UR. Rewards feed the Hidden Treasures fragment economy
  (see the sibling folder).

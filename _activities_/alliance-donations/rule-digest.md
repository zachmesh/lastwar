# Rule digest

1. Donate every run to the recommended node, down to the live-read 1/30 (rule 5); none available, checked only (how-it-is-p1).
2. Read the recommended marker and coin cost fresh each unit (how-it-is-p1, run-20261122-0114-p2).
3. Never press the diamond button without owner approval (how-it-is-p1).
4. Re-read the count after every tap; a greyed tap is unlanded until then (how-it-is-p1, how-it-is-p2).
5. Stop at the live-read 1/30: no tap from 1/30; leave the last donation to a named re-read unit after cooldown (day-20261026-p1, run-20261108-0920-p2, day-20261111, run-20261122-0114-p3).
6. Close only on a live count read in the same unit. Timer hides it: close unverified, tracker untouched, re-read enqueued (day-20261031-hard-p1).
7. The footer is display only, never a closing figure (cadence-section-p2, day-20261031-hard-p1, run-20261122-0114-p2).
8. The count refills about every 20 minutes (unsettled); the closing standard is owed (cadence-section-p1, run-20261122-0114-p1, run-20261122-0114-p2).
9. Re-ground entry from each screenshot; never carry points across framings (how-to-enter-p1).
10. Nothing is claimed by hand for the daily reward (day-20261026-p1).

Unverified: long-press donating (day-20261026-p1: 2-second press does nothing; run-20261122-0114-p3: 1-second press donated, Issue comment only); R3 checkpoint times (day-20261031-hard-p2); Alliance entry in the windowed state (how-to-enter-p7).

# Rule digest

1. Observe only: never claim, fight, dispatch, donate or buy; tap no map pin on a radar stack day (the-job).
2. Resolve every red dot or badge to an action or reason; unexplained ones make the unit partial (the-job).
3. Log each signal in the day file, append-only (the-job, what-this-activity).
4. The reset boundary is 02:00 UTC, not 19:00 local (cadence-section).
5. Never switch the furnace, donate coal, tap Teleport or press Buy (run-20261107-2311-p3, run-20261108-0440-p3, run-20261102-1801-p2).
6. Ground each tap fresh, never reuse a point after a pan; stop after two no-change taps (run-20261102-1801-p2, run-20261110-1521-p2, run-20261103-0508-p2).
7. Re-read the rotating Events strip; re-ground each tab per opening (run-20261108-1615-p3, run-20261111-1946-p1).
8. Seed no zombie chain unless its tab is seen live; none on 2026-11-21 (run-20261121-1551-p1, run-20261107-2121-p2).
9. Settled: Gold Bricks on the base, Alliance Contribution in Alliance Techs, WORLD badge is unread chat (day-20261121-p1, day-20261122-p1, day-20261121-p4).
10. On an outcome_unknown lock stop input and never use open_app Mission Control; only a local user submission clears it (day-20261107-p1, day-20261107-p5).

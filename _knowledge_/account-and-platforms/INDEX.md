## Mac mini install, verified 2026-10-25

1. Mac App Store, search Last War, switch to **iPhone and iPad Apps**, and
   install `Last War:Survival` by FUNFLY PTE. LTD. (designed for iPad).
   No emulator is needed on Apple silicon.
2. Install path `/Applications/LastWar.app`, version 1.0.366, asset version
   2163.1510_826F_39703.23585.
3. First launch runs an age gate, then a game update of about 891.85 MB.
4. On the Start screen choose **Already Have an Account**, then Game Center,
   then the character, then Yes. A further 67.19 MB update follows, then the
   base opens.
5. The App Store step needs the Apple account password typed by the owner
   on the machine. Remote control works in the background and its window can
   sit behind other windows, so the owner may not see the prompt.

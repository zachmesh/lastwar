# Moved paths

[moved-paths.csv](moved-paths.csv) maps the old path of each run article that moved from `_activities_/<activity>/` to `_run_notes_/<activity>/` to its new path and to the dated record it duplicates: 366 rows (old_path, new_path, record). Records and other pages that cite an old path are never edited; resolve the path here. Back to the [run notes](../INDEX.md).

# Duties - researcher

## Each question

1. State the question and the decision it would change.
2. Gather at least two independent, dated sources; record the URLs.
3. Write the claim and the one local observation that could falsify it.
4. Check the claim against a live game observation or an existing record.
5. Write the note under `_records_/<date>/research/` with a verdict:
   `supported`, `contradicted` or `unverified`.
6. Propose a play-rule change only for `supported`; send it to the coordinator.

## Cadence

Two questions per day, chosen from the scout's unexplained items and the
coach's top leaks. A question already answered in `_knowledge_` is not
re-researched; cite the existing answer.

## Record

Write the run at `_records_/<date>/<activity>/<HHMM>-run.md` and append the
day index. The record carries inputs, outputs, stats and follow-up.

### OD-20261123-04 - public repository carries the owner account name and alliance tag

- opened: 2026-11-23
- item: a scan of the tracked files at HEAD on 2026-11-23 found the owner
  account's in-game name in 172 files (152 records, 18 activity files, 1 log,
  1 queue file; 375 lines) and the alliance tag in 334 files (276 records, 57
  activity files, 1 log; 810 lines). The repository page is public (HTTP 200).
  The account privacy convention
  (`_conventions_/local-conventions/account-privacy.md`) keeps both out of
  repository content.
- context: found while delivering the day's records. The ten delivered files
  that carried them were redacted before their first commit (12 tag and 4 name
  replacements, neutral markers). The older occurrences predate the team and
  also sit in git history. The scan used patterns held in code and printed
  counts and paths only, never a value. Allies' in-game names also appear in
  records; they were not counted.
- decision needed (owner): (1) redact the current tree with neutral markers -
  activity profiles are versioned knowledge, records are immutable (C1) - and
  who does it; (2) rewrite git history, or accept that earlier commits keep
  the values; (3) keep the repository public in the meantime; (4) whether
  allies' names are redacted too.
- interim safeguards, no decision needed: seats never write either value; a
  local denylist check in the commit gate (toolsmith); the delivered records
  are clean.
- status: DECIDED 2026-11-23T06:2xZ (owner, 2026-11-22 22:2x PT, relayed by the Steward)
- decision: Owner, 2026-11-22 22:2x PT: "remove my name from all the files; no
  need to change git history; keep the repo public in between; you can keep
  names in the game, but not my name." (1) Redact the current tree, the
  owner's own in-game name ONLY, in ALL tracked files including records and
  logs: an explicit owner exception to C1 (records immutable); the replacement
  keeps every file, changes only the name, and the originals remain in git
  history. (2) History is NOT rewritten. (3) The repository stays public. (4)
  Scope narrowed: other in-game names (alliance names and tags, rival
  alliances, allies, other players) stay allowed; numeric IDs, e-mails, real
  names and contact data stay out. Marker: the phrase "owner account".
  Interim: the no-value rule applies to the owner name only.

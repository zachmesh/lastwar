- Implemented issue #652 in PR #656 (branch
  work/narrow-control-compensation-652, commit 0af7ee6c4, from
  main 533e46010): tapcal.py 1.4.0 -> 1.5.0 gains a `narrow`
  subcommand. Given a grounded target, the control half-width
  and half-height, and the session compensation file, the
  uncompensated tap lands at target + offset: when that landing
  falls outside the control on any axis the verdict is
  compensate-first with the compensated aim, and when it stays
  inside on both axes the verdict is uncompensated-ok. A
  landing exactly on the control boundary counts as a miss, so
  an offset that meets the half-extent already forces
  compensation. The subcommand refuses to judge without a
  session compensation file, and --geometry refuses a
  compensation recorded for another geometry: the offset is per
  session, not per geometry - a 2026-11-10 session (#575)
  measured about +70 right, -14 up in the same fullscreen
  geometry, so a compensation carried across sessions would
  mis-aim. `_tools_/INDEX.md` tapcal row updated. PR #656

## What changed

- `_tools_/scout_diff.py` gains `shared_pool_done_units()`:
  it reads the shared main-checkout pool's done/ records
  through `Q.completion_home` (the same shared home queue.py
  uses for completion markers) and adds those unit ids to the
  diff's closed set. A file counts when it names its unit and
  carries a result status, mirroring `Q._has_done_record`:
  any result status (done, partial, failed,
  skipped-needs-owner, expired) means the unit already closed.
  No new flags, no planner-invocation change: the fix rides
  the existing --root.
- Slots suppressed only through the shared pool are counted
  separately (`already_queued_shared_pool_done` /
  `shared_pool_closed`) so the retro can see which input saved
  each re-enqueue; the two lists partition the suppressions
  (branch plus markers under `branch_closed`, shared-pool-only
  under `shared_closed`). Coverage report, round summary and
  text output carry the new line.
- `_tools_/INDEX.md` scout_diff row documents the new
  behaviour.

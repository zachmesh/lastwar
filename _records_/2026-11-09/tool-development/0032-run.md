- _tools_/tapcal.py 1.1.0 -> 1.2.0: new `verify` subcommand.
  Given a verification case (activity, grounded target,
  optional session compensation from calibrate, max_retries,
  attempts in order) it decides verified / retry with a
  compensated next aim / exhausted / unverified / not-started
  for that target. Next aim is computed from measured error:
  both ends measured -> aim + (observed - tapped); only the
  element re-grounded -> that element under the session
  compensation; only the tap landed -> aim + (target - tapped);
  no measurement -> no aim. A session offset is never applied
  twice. Attempts are consecutive from 1 and a verified
  attempt ends the loop; malformed cases fail loudly (exit 2,
  entry named). One case covers one window geometry (issue
  #475). Miss (tapped - target) and ground (observed - target)
  are reported per attempt under the same convention as score.

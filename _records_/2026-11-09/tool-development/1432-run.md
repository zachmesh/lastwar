## What changed

- `_tools_/scout_diff.py` gains `_is_empty_list_marker()`: a
  label is the prose form of an empty list when it is
  `none`/`empty`, or starts with `none`/`empty` followed by a
  space or an opening parenthesis (case-insensitive), so
  `- none (...)` block lines and `unmatched_labels: none (...)`
  scalars are skipped instead of filed as exploration
  candidates. A real label such as `nonexistent-thing` does not
  match: the marker word must end the text or be followed by a
  space or `(`. Applied in all three parse paths: block lists,
  inline scalars/flow lists, and JSON lists.
- New `_strip_inline_comment()`: a trailing ` # ...` YAML
  comment is dropped before the marker check, so
  `unmatched_labels: none  # ...` no longer files a label (the
  second trap in #527); a `#` glued to a word is still part of
  the value.
- `_tools_/INDEX.md` scout_diff row documents the new
  behaviour.

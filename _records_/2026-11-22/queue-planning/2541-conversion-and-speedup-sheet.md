# Conversion procedure and speed-up use, 2541

## Conversion procedure, one run each

Inventory, Resources tab. It opens with the 5,000 Diamonds x16 tile SELECTED and a live Use (80,000 diamonds): first tap the intended tile, confirm its name in a frame, and never press Use while any other tile is selected. The plain Resource Chest defaults to its FULL stock (20,862). A tap on the number field opens no keypad; use the slider handle, minus or plus. Read the number field (and the Total line for Coin Chests) in a frame BEFORE Use, then Use. In the choice popup choose only the 6K Coin option; stop and record if it shows anything else or a cost. Read coin before and after.

Construction items (167,760 minutes): 8h x10 (4,800 minutes), 1h x26 (1,560), 5m x28,477, 1m x19,015. General items (351,647 minutes) stay in reserve. Nothing is pressed if the number cannot be read. Never Finish Now, diamonds or money.

# Activity executions

Instance folder. One leaf file per activity type, matching the folder of
the same name under `_activities_`. Each round appends one dated entry to
the file of every activity it touched, stating performed, performed in
part, checked only, or not performed, with the session window and the
outcome. Entries are append-only under constitution C1 and are never
edited once committed - a correction is a new appended entry.

To answer whether and when an activity was performed, open its file
here. For the narrative of a whole day, see
[`play-sessions/`](../play-sessions/INDEX.md).
